# personaje-vinilo-blender

Skill para Claude Code: crea tu propio personaje 3D estilo juguete de vinilo en Blender (el agente lo modela por MCP) y lo convierte en capas animadas para una web. Es el método con el que se hizo el conejo de Bunny Records.

## Instalar

1. Copia esta carpeta a `~/.claude/skills/personaje-vinilo-blender/` (en Windows: `C:\Users\<tú>\.claude\skills\`).
2. Sigue `references/instalacion.md` (Blender ≥ 5.1 + servidor MCP de Blender Lab).
3. Abre Blender, después Claude Code, y pide algo como: *"Quiero crear mi personaje con el skill personaje-vinilo-blender"*.

El agente irá fase por fase (brief → blockout → material → hoja → poses → capas → web) y te pedirá aprobación en cada una. El diseño lo decides tú: el estilo del conejo es solo el punto de partida.
